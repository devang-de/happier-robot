Cognee Integration — Self-Learning Agent Brain

TUM.AI x HappyRobot Hackathon 2025  |  Devang Dhumal

Overview

Cognee powers the agent's persistent memory and continuous learning system. Every interaction — every call, every email, every negotiation — is stored in a structured knowledge graph and recalled when relevant context is needed.

The brain operates on two fundamental loops: Recall (retrieving prior context before conversations) and Learn (extracting and storing new knowledge after interactions). This makes the agent progressively smarter: the next prospect benefits from every previous conversation.

Memory Architecture

How Recall Works

Before every conversation, the agent queries Cognee for relevant prior knowledge. This ensures continuity across interactions — the agent remembers past discussions, negotiation positions, and company-specific requirements.

// Agent receives a call or prepares an email // Step 1: Identify the caller/lead Agent receives call → Identifies caller from Twin DB // Step 2: Query Cognee for prior context POST /api/v1/recall { "query": "Allianz Devang insurance fleet management" } // Step 3: Cognee returns relevant memories → Returns: prior context, negotiation history, patterns, product info // Step 4: Agent weaves context into conversation naturally → "Last time we spoke, you mentioned needing BaFin compliance..."

How Learning Works

After every interaction, the system extracts key information and stores it in the appropriate Cognee datasets. This creates a growing knowledge base that improves future conversations.

// Call ends → Post-call extract generates structured data // Store lead-specific context POST /api/v1/add_text { "text_data": [ "INBOUND CALL — Company: Allianz | Contact: Devang |" "Stage: negotiation | Summary: Discussed fleet management" "pricing for 500 vehicles. Needs BaFin-compliant DPA." "Requested 15% discount. Budget: Q3 approval cycle." ], "datasetName": "lead_context" } // Store generalizable pattern POST /api/v1/add_text { "text_data": [ "Insurance companies need BaFin-compliant DPA before" "procurement approval. Always prepare DPA early." ], "datasetName": "brain_patterns" }

What the Brain Learns

Over time, the brain accumulates generalizable sales intelligence that makes every future conversation more effective. Here are examples of actual patterns the brain stores:

"Insurance companies typically need BaFin-compliant data retention before procurement approval. Always prepare DPA documentation early in the sales cycle."
"Enterprise 3-year deals: maximum 15% discount with dedicated CSM included. Anything above requires VP approval and custom SOW."
"When competitors are mentioned, ask for written evidence of competitor pricing before engaging in price matching. Never match verbally quoted figures."
"Fleet management prospects with 500+ vehicles typically have 6-month procurement cycles. Set follow-up cadence accordingly and involve technical SE early."
"German enterprise customers strongly prefer German-language contracts even when negotiations are conducted in English. Always offer localized documentation."
